# Smart Retail Inventory Intelligence System

## 📌 Project Overview
This project analyzes 2 years of retail sales data to optimize inventory levels, understand demand patterns, and improve business decision-making using data analytics.

## 📊 Dataset Information
- 73,100 records
- 5 stores
- 20 products
- 5 categories
- 4 regions
- 2 years of daily data

## 🎯 Key Objectives
- Analyze sales performance across stores and products
- Identify revenue-generating categories and products
- Detect inventory overstock and understock conditions
- Improve inventory decision-making using demand patterns

## 🧮 KPIs Built
- Total Revenue
- Total Units Sold
- Inventory Level Analysis
- Stockout Risk Detection
- Overstock Detection
- Inventory Gap Analysis

## 🔍 Key Insights
- Revenue is evenly distributed across stores and categories
- No stockout cases detected (synthetic dataset behavior)
- Significant overstock conditions observed
- Inventory optimization opportunities identified

## 🛠 Tools Used
- Python (Pandas, Matplotlib)
- VS Code
- Jupyter Notebook

## 📈 Final Output
- Inventory Risk Dashboard
- Product Performance Analysis
- Business KPI Reports
